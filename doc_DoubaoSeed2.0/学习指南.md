## 项目简介

JPetStore 6 是一个完整的宠物商店 Web 应用程序，它是 MyBatis 官方提供的示例项目。该项目展示了如何将 MyBatis、Spring 和 Stripes 框架整合使用，构建一个功能完整的电商网站。

### 主要功能
- 用户注册和登录
- 商品浏览（按分类、商品、商品项）
- 购物车管理
- 订单处理
- 商品搜索

### 关键包说明

1. **domain** - 存放实体类（POJO）
   - Account.java - 用户账户
   - Category.java - 商品分类
   - Product.java - 商品
   - Item.java - 商品项（具体商品）
   - Order.java - 订单
   - Cart.java - 购物车

2. **mapper** - MyBatis 数据访问接口
   - 对应 domain 中的实体，提供 CRUD 操作

3. **service** - 业务逻辑层
   - AccountService - 用户服务
   - CatalogService - 商品目录服务
   - OrderService - 订单服务

4. **web/actions** - Web 控制器
   - 处理 HTTP 请求，调用 service 层，返回视图

## 快速启动

### 方式一：使用 Maven 直接运行（推荐新手）

【**用idea启动的方法**：Maven，选[Lifecycle]-[clean]后再选[package]，然后执行[Plugins]-[cargo]-[cargo-run]】

1. **打开命令行，进入项目目录**
```bash
cd d:\Project\Java\jpetstore6
```

2. **编译项目**
```bash
.\mvnw clean package
```

3. **启动 Tomcat 服务器**
```bash
.\mvnw cargo:run -P tomcat9
```

4. **访问应用**
打开浏览器，访问：http://localhost:8080/jpetstore/

5. **停止服务器**
在命令行按 `Ctrl + C`



### 方式二：使用 Docker

```bash
# 构建镜像
docker build . -t jpetstore

# 运行容器
docker run -p 8080:8080 jpetstore

# 或使用 Docker Compose
docker compose up -d
```

## 核心模块详解

### 1. Domain 层 - 实体类

以 `Account.java` 为例（`src/main/java/org/mybatis/jpetstore/domain/Account.java`）：

```java
public class Account implements Serializable {
  private String username;
  private String password;
  private String email;
  private String firstName;
  private String lastName;
  // ... 其他字段和 getter/setter
}
```

**学习要点：**
- 这是一个标准的 POJO 类
- 实现了 `Serializable` 接口，用于序列化
- 使用 Stripes 的 `@Validate` 注解进行数据验证
- 每个字段都有对应的 getter 和 setter 方法

### 2. Mapper 层 - 数据访问

以 `ProductMapper.xml` 为例（`src/main/resources/org/mybatis/jpetstore/mapper/ProductMapper.xml`）：

```xml
<mapper namespace="org.mybatis.jpetstore.mapper.ProductMapper">
  <select id="getProduct" resultType="Product">
    SELECT PRODUCTID, NAME, DESCN as description, CATEGORY as categoryId
    FROM PRODUCT
    WHERE PRODUCTID = #{productId}
  </select>
  
  <select id="getProductListByCategory" resultType="Product">
    SELECT PRODUCTID, NAME, DESCN as description, CATEGORY as categoryId
    FROM PRODUCT
    WHERE CATEGORY = #{value}
  </select>
</mapper>
```

**学习要点：**
- `namespace` 对应 Mapper 接口的全限定名
- `id` 对应接口中的方法名
- `resultType` 指定返回结果的类型
- `#{xxx}` 是参数占位符
- 字段别名（如 `DESCN as description`）用于映射到 Java 对象的属性

对应的接口 `ProductMapper.java`：
```java
public interface ProductMapper {
  Product getProduct(String productId);
  List<Product> getProductListByCategory(String categoryId);
  List<Product> searchProductList(String keywords);
}
```

### 4. Web 层 - 控制器

以 `CatalogActionBean.java` 为例（`src/main/java/org/mybatis/jpetstore/web/actions/CatalogActionBean.java`）：

```java
@SessionScope
public class CatalogActionBean extends AbstractActionBean {
  
  @SpringBean
  private transient CatalogService catalogService;
  
  @DefaultHandler
  public ForwardResolution viewMain() {
    return new ForwardResolution(MAIN);
  }
  
  public ForwardResolution viewCategory() {
    if (categoryId != null) {
      productList = catalogService.getProductListByCategory(categoryId);
      category = catalogService.getCategory(categoryId);
    }
    return new ForwardResolution(VIEW_CATEGORY);
  }
}
```

**学习要点：**
- 使用 `@SessionScope` 注解指定作用域
- 使用 `@SpringBean` 注入 Spring 管理的 Bean
- 每个方法对应一个请求处理
- `ForwardResolution` 指定返回的视图页面
- `@DefaultHandler` 指定默认处理方法

### 5. 视图层 - JSP

JSP 页面位于 `src/main/webapp/WEB-INF/jsp/` 目录下。

**学习要点：**
- 使用 JSTL 标签库
- 使用 EL 表达式访问数据
- Action 中的属性可以在 JSP 中直接访问

## 常见问题

### Q1: 运行 `mvnw` 时提示找不到命令？
**A:** 确保在项目根目录下运行，并且文件 `mvnw.cmd` 存在。在 Windows 上使用 `.\mvnw`。

### Q2: 启动 Tomcat 时端口被占用？
**A:** 
- 检查 8080 端口是否被其他程序占用
- 可以修改 `pom.xml` 中的端口配置
- 或者关闭占用端口的程序

### Q3: 如何导入项目到 IDEA？
**A:**
1. 打开 IDEA
2. 选择 `File` → `Open`
3. 选择项目根目录（`d:\Project\Java\jpetstore6`）
4. IDEA 会自动识别 Maven 项目并导入

### Q4: 数据库在哪里？数据会持久化吗？
**A:** 
- 项目使用 HSQLDB 内存数据库
- 数据存储在内存中，服务器重启后数据会丢失
- 数据库初始化脚本在 `src/main/resources/database/`

### Q5: 我想换成 MySQL 数据库，可以吗？
**A:** 可以！需要：
1. 修改 `pom.xml`，添加 MySQL 驱动依赖
2. 修改 `applicationContext.xml`，配置 MySQL 数据源
3. 修改数据库脚本，适配 MySQL 语法
