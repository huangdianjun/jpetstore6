# JPetStore 6 项目总结

## 项目概览

JPetStore 6 是 MyBatis 官方提供的示例项目，展示了如何使用 MyBatis、Spring 和 Stripes 构建一个完整的宠物商店 Web 应用。

### 核心价值
- **学习参考**：作为 MyBatis 的最佳实践示例
- **技术整合**：展示主流 Java 技术栈的整合方式
- **架构示范**：展示清晰的分层架构设计

---

## 架构设计

### 三层架构

```
┌─────────────────────────────────────────────────────────┐
│                     Web 层 (Presentation)                │
│  Stripes ActionBeans + JSP                              │
└────────────────────────────┬────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────┐
│                   Service 层 (Business)                  │
│  AccountService, CatalogService, OrderService           │
└────────────────────────────┬────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────┐
│                   Mapper 层 (Persistence)                │
│  MyBatis Mappers + XML Mapping Files                    │
└────────────────────────────┬────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────┐
│                     数据库层 (Database)                   │
│  HSQLDB (内存数据库)                                      │
└─────────────────────────────────────────────────────────┘
```

### 各层职责

| 层级 | 职责 | 关键类/文件 |
|------|------|-------------|
| Web 层 | 处理 HTTP 请求、参数绑定、返回视图 | `*ActionBean.java`, `*.jsp` |
| Service 层 | 业务逻辑、事务管理、组合多个 Mapper 操作 | `*Service.java` |
| Mapper 层 | 数据访问、SQL 映射 | `*Mapper.java`, `*Mapper.xml` |
| Domain 层 | 数据模型、实体类 | `*.java` (domain 包下) |

## 核心数据模型

### 实体关系图

```
Category (分类)
    │
    ├── 1 ── N
    │
Product (商品)
    │
    ├── 1 ── N
    │
Item (商品项)
    │
    ├── 1 ── N
    │
LineItem (订单明细)
    │
    ├── N ── 1
    │
Order (订单)
    │
    ├── N ── 1
    │
Account (用户账户)
    │
    └── 1 ── N
          │
        Cart (购物车)
```

### 主要实体说明

1. **Account** - 用户账户
   - 存储用户基本信息
   - 包含登录凭证、地址、偏好设置等

2. **Category** - 商品分类
   - 如鱼类、狗类、猫类、爬行类、鸟类
   - 包含分类ID、名称、描述

3. **Product** - 商品
   - 一个分类下有多个商品
   - 如"Angelfish"（神仙鱼）

4. **Item** - 商品项
   - 一个商品下有多个具体的商品项
   - 包含价格、库存、供应商等信息

5. **Order** - 订单
   - 包含订单号、用户信息、收货地址、订单明细等

6. **Cart** - 购物车
   - 存储用户选择的商品项

## 技术详解

### 1. MyBatis 配置

**配置文件位置：** `src/main/resources/`

**关键配置：**
- `applicationContext.xml` - Spring 整合 MyBatis
- `*Mapper.xml` - SQL 映射文件

**MyBatis 特性使用：**
- `@Cache` - 二级缓存
- 结果映射（自动映射 + 别名）
- 参数映射
- SQL 语句分离

### 2. Spring 配置

**配置文件：** `src/main/webapp/WEB-INF/applicationContext.xml`

**Spring 管理的组件：**
- DataSource（数据源）
- SqlSessionFactory
- Mapper 接口
- Service 层 Bean

### 3. Stripes Web 框架

**特点：**
- 约定优于配置
- 注解驱动
- 简单的 ActionBean 模型
- 强大的绑定和验证

**Stripes 关键注解：**
- `@DefaultHandler` - 默认处理方法
- `@SpringBean` - 注入 Spring Bean
- `@SessionScope` - Session 作用域
- `@Validate` - 参数验证

## 核心功能流程

### 1. 用户注册/登录流程

```
1. 用户访问注册页面
   ↓
2. 填写表单，提交到 AccountActionBean.newAccount()
   ↓
3. Stripes 自动绑定参数到 Account 对象
   ↓
4. 调用 AccountService.insertAccount()
   ↓
5. AccountMapper.insertAccount() 执行 SQL
   ↓
6. 数据保存到 HSQLDB
   ↓
7. 返回登录页面或自动登录
```

### 2. 商品浏览流程

```
1. 用户点击分类（如 "Fish"）
   ↓
2. 请求到 CatalogActionBean.viewCategory()
   ↓
3. 调用 CatalogService.getCategory() 和 getProductListByCategory()
   ↓
4. ProductMapper 执行 SQL 查询
   ↓
5. 数据返回到 ActionBean
   ↓
6. 转发到 Category.jsp 展示商品列表
```

### 3. 购物车和下单流程

```
1. 用户添加商品到购物车
   ↓
2. CartActionBean 处理，更新 Cart 对象（Session 中）
   ↓
3. 用户点击结账
   ↓
4. OrderActionBean 处理，收集订单信息
   ↓
5. OrderService.insertOrder() 保存订单
   ↓
6. 多个 Mapper 参与（OrderMapper, LineItemMapper, ItemMapper）
   ↓
7. 清空购物车，显示订单确认页面
```

## 代码最佳实践

### 1. 分层清晰
- 每一层只依赖下一层
- 不跨层调用
- 职责单一

### 2. 使用接口编程
- Mapper 层使用接口
- Service 层可以定义接口（虽然本项目没有）

### 3. 依赖注入
- 使用 Spring 的 `@Autowired`（或 Stripes 的 `@SpringBean`）
- 不手动 new 对象

### 4. 测试覆盖
- 每一层都有对应的单元测试
- 有集成测试

### 5. 配置外部化
- SQL 在 XML 文件中
- Spring 配置在 XML 文件中
- 不硬编码

## 学习心得

### 为什么这个项目适合新手？

1. **代码量适中** - 不会太复杂，也不会太简单
2. **架构清晰** - 标准的三层架构
3. **技术主流** - 使用的都是业界主流技术
4. **文档齐全** - 有官方文档和社区资源
5. **可运行** - 可以快速看到效果

### 从这个项目可以学到什么？

1. **MyBatis 的使用** - 注解、XML 映射、缓存等
2. **Spring 的使用** - IoC、依赖注入、整合等
3. **Web 开发** - MVC、请求处理、会话管理等
4. **项目结构** - 如何组织一个 Java Web 项目
5. **最佳实践** - 分层、接口编程、测试等
