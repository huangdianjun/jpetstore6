## 🔧 快速启动命令

```bash
# 进入项目目录
cd d:\Project\Java\jpetstore6

# 编译项目
.\mvnw clean package

# 启动服务器
.\mvnw cargo:run -P tomcat9

# 访问应用
# 浏览器打开: http://localhost:8080/jpetstore/
```
